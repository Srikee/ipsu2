# Commit Message Generation Rule

หลังจากที่เขียน, แก้ไข หรือปรับปรุงโค้ดเสร็จสิ้นในแต่ละรอบ ให้สร้าง **Commit Message** เป็นภาษาไทยสรุปเนื้อหาการเปลี่ยนแปลงไว้ท้ายคำตอบเสมอ โดยปฏิบัติตามข้อกำหนดดังต่อไปนี้อย่างเคร่งครัด:

1. **ส่งเฉพาะข้อความ (Plain Text Inside Codeblock):**
   - ให้วางข้อความ commit message ไว้ในบล็อกโค้ด (```text ... ```) เพื่อให้ผู้ใช้สามารถกดปุ่ม Copy ได้ในคลิกเดียว
   - **ห้ามใส่คำสั่ง Git เด็ดขาด** เช่น ห้ามใส่ `git commit -m "..."`, `git add`, หรือคำสั่ง shell อื่น ๆ

2. **ภาษาและโครงสร้างของข้อความ:**
   - เขียนสรุปเนื้อหาเป็น **ภาษาไทย** ที่กระชับ ชัดเจน และตรงประเด็น
   - สามารถระบุประเภทการทำงานนำหน้า เช่น `feat:`, `fix:`, `style:`, `refactor:` ตามด้วยรายละเอียด
   - หากมีการเปลี่ยนแปลงหลายจุด ให้ใช้ bullet point (-) สรุปเป็นข้อย่อยได้

ตัวอย่างรูปแบบที่ถูกต้อง:
```text
feat(profile): ปรับปรุงหน้าโปรไฟล์เป็น Digital ID Card และเพิ่มระบบซูมรูปโปรไฟล์

- ออกแบบการ์ดบัตรประจำตัวดิจิทัล (Virtual ID Card) โทนสี PSU Blue
- เพิ่มการจัดกลุ่มข้อมูลการศึกษา ข้อมูลส่วนบุคคล และช่องทางติดต่อเป็นการ์ด
- เพิ่มฟังก์ชันแตะรูปโปรไฟล์เพื่อขยายดูรูปขนาดใหญ่พร้อมเอฟเฟกต์ Spring Zoom
- เพิ่มปุ่มคัดลอกรหัสประจำตัวและปุ่มซ่อน/แสดงเลขบัตรประชาชน
```
